Repeatable workflows for data processing, spreadsheet automation, report generation, and analytical review.

## Publishing Standard

A project will be listed here only when it includes:

- A clear problem statement
- Reproducible setup or usage instructions
- Meaningful documentation
- Honest limitations
- Screenshots, examples, or evaluation notes when useful
